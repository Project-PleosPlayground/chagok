# 02. 화면 목록

화면 구성은 대부분 `[미정]`이다. 아래는 지금까지 나온 후보와 이미 정해진 제약이다.

## 화면 후보

| 화면 | 언제 | 정해진 것 | 미정 |
|---|---|---|---|
| 정차 홈 (캐릭터) | 정차 중 | 캐릭터 크기: 빈 곳 높이에 맞춘 스테이지에서 계산. 시연 기준 2칸 창 프레임 511 dp `가안` ([스펙_스테이지](스펙_스테이지.md#화면별-스테이지-크기)) | 메뉴 구성 `[미정]` |
| 주행 중 화면 | 주행 중 | 앱에 들어온 뒤(홈과 그 밖의 화면)에 주행이 시작되면 홈(주행 화면)으로 가서 주행이 끝날 때까지 머문다. 앱에 들어오기 전(온보딩, 프로필 선택·추가)에 주행이 시작되면 화면은 그대로 두고, 화면 위 창 전체에 반투명 막과 흰 큰 글씨 "주행중 / 안전 운전 하세요 / ヾ(≧ ▽ ≦)ゝ"를 덮어 주행이 끝날 때까지 조작을 막는다. 음성은 그대로 낸다([05_음성.md](05_음성.md)) | 막은 ink 85% `[임시]`. 작은 상태 아이콘을 둘지, 아무것도 안 보일지 `[미정]`. 캐릭터를 보일 경우 크기는 화면 빈 곳에 맞춘 스테이지에서 계산 ([스펙_스테이지](스펙_스테이지.md#화면별-스테이지-크기)) |
| 세션 리포트 | 세션 종료 후 정차 중 | 세션 점수, 세부 점수(가속·제동·매너). 세부 점수 옆에 이벤트 횟수도 표시한다("급제동 2회"). 종료 안내창의 캐릭터 크기: 화면 빈 곳에 맞춘 스테이지에서 계산, 빈 곳은 `[미정]` ([스펙_스테이지](스펙_스테이지.md#화면별-스테이지-크기)) | 레이아웃은 [영역사양_주행결과화면](화면/영역사양_주행결과화면.html). 시안은 가속·제동·매너 세부 점수 대신 별점과 4항목 요약을 보인다 `[확인필요]` |
| 통계 (주행 기록) | 정차 중 | 달력에서 날짜를 고르면 그날의 주행 목록(점수, 한 줄, 시각, 거리, 출발 → 도착)이 나온다. 주행을 누르면 상세가 열리고, 감점 행동마다 시각을 보인다. 위치 기록을 켰으면 도로명도 보인다. 유효 주행이 아닌 주행([07](07_미션.md))은 달력, 목록, 누적 점수, 그래프에 넣지 않는다. 주행 기록은 기기 안에 모두 남기고 개수 제한을 두지 않는다. 프로필을 지우면 함께 지운다 (#14) | - |
| 미션 | 정차 중 | 미션 탭, 미션 오버레이, 완료 미션 화면 ([07](07_미션.md) "화면") | - |

## 주행·정차 분기 (확정)

- 주행 중에는 키보드 입력과 설정 변경을 하지 않는다. 이름 짓기, 설정은 정차 중에만.
- 주행 여부는 시스템 주행 규제(`CarUxRestrictionsManager.isRequiresDistractionOptimization()`)와 주행 세션(출발해 세션이 열림) 중 하나라도 해당하면 주행 중으로 본다(#76).
  - 주행 규제는 기어가 P가 아니면 정차 중에도 걸린다(D·N·R단). 출발 전 D단 정차, 신호 대기, 세션이 끝난 뒤의 D단 정차도 주행 중이다(Pleos 에뮬레이터 확인. 실차는 `[확인필요]`).
  - 주행 규제는 속도 권한 없이 읽으므로, 권한을 받기 전(첫 실행)에도 주행 여부를 안다.

출처: [조사 체크리스트 2절](../조사/API가용범위_기획체크리스트.md)

## 화면 층 (확정)

화면은 **스테이지 층**과 **UI 층**으로 그린다.

| 층 | 그리는 것 | 순서 |
|---|---|---|
| 스테이지 층 | [스펙_스테이지 "스테이지"](스펙_스테이지.md#스테이지)에 놓이는 캐릭터, 펫, 소품, 배경 | 층 안의 순서는 [스펙_스테이지 "렌더 순서"](스펙_스테이지.md#렌더-순서)를 따른다 |
| UI 층 | 버튼, 글, 미션 오버레이처럼 화면을 기준으로 놓이는 요소 | 스테이지 층 위에 그린다 |

- 두 층은 서로의 위치에 영향을 주지 않는다. 각 층의 요소는 자기 자리에 놓인다. UI가 스테이지를 가려도 된다.
- 팝업은 두 층과 따로 띄운다.

아래 표는 화면별로 층을 어떻게 놓는지다.

| 화면 | 층 |
|---|---|
| 홈 | 스테이지 층 위에 UI 층(홈 UI, 미션 오버레이)을 겹친다 |
| 상점 | 화면을 반으로 나눈다. 아이템 목록 쪽은 UI 층만 있고 스테이지가 없다. 스테이지 쪽은 스테이지 층 위에 버튼(저장 등)의 UI 층을 겹친다 |

- 미션 오버레이의 위치와 크기는 `[미정]`이다.
- 스테이지를 창 안 어디에 놓을지는 `[미정]`이다([스펙_스테이지 "화면별 스테이지 크기"](스펙_스테이지.md#화면별-스테이지-크기)).

## 지금 앱에 있는 화면

- 온보딩: 앱을 새로 켤 때 1.5초 보인 뒤 프로필 선택으로 간다. 시동음을 낸다.
  - 주행 중에 새로 켜면 온보딩 화면에서 멈춘다. 시동음을 내지 않고 프로필 선택으로 넘어가지 않으며, 주행 중 막이 덮는다. 주행이 끝나면 그때 시동음과 1.5초를 시작한다(#76).
  - 온보딩 도중에 주행이 시작되면 멈추고, 주행이 끝난 뒤 처음부터 다시 한다.
- 권한 요청: 앱을 켜면 바로 시스템 권한 창을 띄운다(차량 신호, 위치). 주행 중에 처음 켰을 때 미룰지는 `[미정]`(#76).
- 프로필 선택: 온보딩 다음에 나온다. 설정의 "프로필 선택" 버튼으로도 온다(정차 중에만). 이때도 앱을 켰을 때처럼 프로필 선택에서 다시 시작해, 뒤로 가기는 앱을 숨긴다(#119).
  - 프로필을 고르면 그 프로필의 데이터로 바꾸고 홈으로 간다(#105). 홈·미션·상점·리포트·설정, 주행 기록, 미션 판정, AI 리포트 동의가 모두 고른 프로필 것이다. 주행 중에는 바꾸지 않는다.
  - 앱을 다시 켜면 지난번에 고른 프로필로 시작한다. 프로필 선택 화면은 그대로 나온다. 지난번 프로필이 지워졌으면 먼저 만든 프로필로 시작한다.
  - 프로필은 프로필 추가로만 만든다. 첫 프로필은 프로필을 만들기 전에 쌓인 포인트·아이템, 주행 기록, 받은 미션을 이어받는다. 캐릭터는 추가 화면에서 고른 차로 정한다. 그 차를 이미 키웠으면 그 성장이 이어진다.
  - 추가 버튼을 누르면 프로필 추가가 위에 뜨고, 저장·취소하면 프로필 선택으로 돌아온다.
  - 프로필 관리에서 카드를 누르면 프로필 수정이 뜬다. 프로필 추가와 같은 화면에 지금 이름·차가 채워져 있고, 오른쪽 위 삭제 버튼으로 확인 팝업을 거쳐 그 프로필의 데이터를 지운다(#111). 지금 쓰던 프로필을 지우면 남은 프로필 중 먼저 만든 것으로 바꾼다.
- 탭 화면 4개: 홈, 미션, 상점, 리포트. 아래 탭으로 오간다.
- 주행 종료: 주행이 끝나면 지금 화면 위에 뜬다. 세션이 끝났어도 D단에 서 있어 주행 규제가 남아 있으면, 주행 화면에 머물다가 P단에 넣을 때 뜬다. 주행 화면의 주행 종료 버튼도 P단에서만 보인다. D단 정차 중에 다시 출발하면 앞 주행의 결과 화면은 건너뛰고, P단에 넣을 때 마지막 주행의 결과만 뜬다(앞 주행도 기록·보상은 그대로 남는다).
- 주행 디버그: 현재 점수, 세션 상태, 최근 이벤트, 마지막 발화, 시연 주행 재생. 시연·개발용이라 디버그 빌드에만 있다.
- 뒤로 가기: 탭 화면에서는 홈으로, 주행 종료·주행 디버그에서는 원래 화면으로 간다. 프로필 추가·수정에서는 취소와 같다. 홈·온보딩·프로필 선택에서는 앱을 끄지 않고 숨긴다(Pleos CCP Back 정책).
- CCP(로터리 컨트롤러): 지원하지 않는다. 매니페스트에 미지원을 선언하고, 모든 조작을 터치로 한다(#88). 뒤로 가기 하드키는 위와 같이 처리한다.
