# 03. 기능 명세

기능별로 **가능 여부**(확인됨)와 **우선순위**(대부분 미정)를 적는다. 가능 여부 근거는 [조사 체크리스트 2절](../조사/API가용범위_기획체크리스트.md).

우선순위: `MVP` = 12/3 PT까지 동작 / `다음` = 그 뒤 / `[미정]` = 팀 결정 전

## 안전운전 측정 (MVP 확정)

| 기능 | 가능 여부 | 쓰는 SDK·API | 우선순위 | 라벨 |
|---|---|---|---|---|
| 급가속 검출 | 가능 (속도 미분) | AAOS `PERF_VEHICLE_SPEED` | MVP | `engine` |
| 급제동 검출 | 가능 | Pleos Brake 페달 + 속도 변화율 | MVP | `engine` |
| 깜빡이 없는 차선변경 | 가능 (추정) | Pleos TurnSignal + SteeringWheel 조향각 | MVP | `engine` |
| 세션 점수·세부 점수 | 가능 | 엔진 계산, Odometer 트립 거리 | MVP | `engine` |
| 주행 중 음성 피드백 | 가능 | Pleos TextToSpeech (ON_DEVICE) | MVP | `voice` |
| 과속 시간 | 조건부 (내비 안내 중만) | NaviHelper `onCurrentRoadSpeedLimit` | 다음 | `engine` |
| 지그재그 운전 | 가능 (추정) | SteeringWheel | 다음 | `engine` |

상세 규칙: [스펙_안전점수.md](스펙_안전점수.md)
