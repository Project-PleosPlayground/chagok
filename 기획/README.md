## 쓰는 법

- 정한 것만 적는다. 정하지 않은 것은 `[미정]`으로 표시하고, 관련 이슈 번호를 옆에 단다. 이슈가 없으면 `결정필요` 라벨로 이슈를 만든다.
- 결정은 이슈 댓글로 하고, 결정이 나면 이 폴더의 해당 문서를 고친다.
- 숫자가 임시값이면 `가안`이라고 적는다.
- 스펙 문서(`스펙_*.md`)는 항상 PR로 고친다. 나머지는 CONTRIBUTING 2절 "그 밖의 문서" 규칙을 따른다.
- 제출용 서류는 이 저장소에 두지 않는다(CONTRIBUTING 2절).
