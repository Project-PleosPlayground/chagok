# 데이터 컬럼 사전

공유 스프레드시트의 탭마다 컬럼의 뜻과 적는 형식을 정한다. 각 탭은 CSV로 내보내 앱이 읽는다. "구분"이 "앱에 들어감"인 컬럼은 앱이 그대로 읽으니 형식을 지킨다. "메모용"인 컬럼은 사람이 보는 칸이라 앱이 읽지 않고, 자유롭게 써도 된다.

모든 탭에 공통인 규칙이다.

- 첫 행은 아래 컬럼명을 그대로 쓴다. 한 셀에 값 하나.
- ID와 키는 한 번 정하면 바꾸거나 다른 줄에 다시 쓰지 않는다. 지운 줄의 ID도 다시 쓰지 않는다.
- 다른 탭의 값을 가리킬 때는 그 탭의 ID나 이름을 그대로 적는다.
- 값이 없는 칸은 비운다.
- UTF-8로 저장한다. 엑셀에서는 "CSV UTF-8(쉼표로 분리)" 형식을 고른다.

## 앱 색상

한 줄 = 색 하나. 키 = 이름.

| 컬럼 | 뜻 | 형식 | 예 | 구분 |
|---|---|---|---|---|
| 이름 | 색 이름 | 영문 소문자, `_` | `primary_blue` | 앱에 들어감 |
| HEX | 100% 색 값 | `#RRGGBB` | `#2563EB` | 앱에 들어감 |
| 용도 | 대표 쓰임 1~2개 | 글 | 주행 시작 버튼 배경 | 메모용 |
| 메모 | | 글 | | 메모용 |

투명도는 여기 적지 않는다. SVG나 쓰는 곳에서 정한다.

## 폰트

한 줄 = 글자 모양 하나. 키 = 역할.

| 컬럼 | 뜻 | 형식 | 예 | 구분 |
|---|---|---|---|---|
| 역할 | 글자 모양의 이름. `크기_굵기`로 짓는다(large·medium·small, bold·regular). 디자인 시스템 5절 | 영문 소문자, `_` | `small_bold` | 앱에 들어감 |
| 폰트 | 글꼴 이름 | 글꼴 이름 그대로 | Pretendard | 앱에 들어감 |
| 크기 | 글자 크기 | 숫자(피그마 px = sp) | 20 | 앱에 들어감 |
| 굵기 | 글자 굵기 | Regular 또는 Bold | Bold | 앱에 들어감 |
| 행간 | 줄 높이 | 숫자(px) `[확인필요]` 피그마가 %로 주면 % | 28 | 앱에 들어감 |
| 자간 | 글자 사이 | % (피그마 값 그대로) | -2 | 앱에 들어감 |
| 메모 | | 글 | | 메모용 |

## UI 텍스트

한 줄 = 화면에 고정된 글 하나. 키 = 키.

| 컬럼 | 뜻 | 형식 | 예 | 구분 |
|---|---|---|---|---|
| 키 | 글 이름 | 영문 소문자, `_` | `save_button` | 앱에 들어감 |
| 문구 | 화면에 보일 글 | 글. 줄바꿈은 `\n` | 저장 | 앱에 들어감 |
| 화면 | 주로 쓰는 화면 | 글 | addProfileView | 메모용 |
| 메모 | | 글 | | 메모용 |

- 화면에 고정된 글만 적는다: 버튼, 안내, 화면 이름표. 미션 이름·설명, 아이템 이름은 콘텐츠 텍스트 탭에 적는다.
- 버튼 글자의 키는 버튼이 하는 일로 짓는다(`save_button` → 저장).
- 폰트·정렬은 적지 않는다. 피그마 화면과 화면 영역 사양서를 따른다.

## 콘텐츠 텍스트

한 줄 = 콘텐츠 글 하나(미션 이름·설명, 아이템 이름). 키 = 키.

| 컬럼 | 뜻 | 형식 | 예 | 구분 |
|---|---|---|---|---|
| 키 | 글 이름 | 영문 소문자, `_` | `mission_brake_name` | 앱에 들어감 |
| 문구 | 보일 글 | 글. `{n}` 자리에 목표치가 들어간다 | 급제동 {n}회 이하 | 앱에 들어감 |
| 메모 | | 글 | | 메모용 |

- `{n}`: 목표치
- 목표치가 0이면 "0회 이하" 대신 "없이"처럼 다른 문구를 쓴다. 같은 키 뒤에 `_zero`를 붙인 줄을 하나 더 두면, 목표치가 0일 때 그 문구가 나온다. `_zero` 줄이 없으면 원래 문구에 0이 들어간다.

  | 키 | 문구 |
  |---|---|
  | `mission_brake_name` | 급제동 {n}회 이하 |
  | `mission_brake_name_zero` | 급제동 없이 |

- 글자 수 상한은 [07 "미션 데이터"](07_미션.md#미션-데이터)를 따른다.

## 미션(조합)

한 줄 = 조건 하나. 키 = 조건ID. 앱은 이 표와 미션 단계 보상 표에서 조건 하나와 단계 하나를 골라 미션을 만든다. 개인(일일) 미션과 주간 미션이 이 표를 같은 풀로 쓴다.

| 컬럼 | 뜻 | 형식 | 예 | 구분 |
|---|---|---|---|---|
| 조건ID | 조건 번호 | 숫자. 아래 조건 번호표의 번호 | 1 | 앱에 들어감 |
| 조건 | 사람이 부르는 이름 | 글 | 급제동 이하 | 메모용 |
| 이름 | 카드 제목 틀 | 콘텐츠 텍스트 키 | `mission_brake_name` | 앱에 들어감 |
| 내용 | 카드 설명 틀 | 콘텐츠 텍스트 키 | `mission_brake_desc` | 앱에 들어감 |
| 아이콘 | 대표 아이콘 | 그림 파일 이름 | `brake_icon` | 앱에 들어감 |
| 목표치_1단계 ~ 목표치_4단계 | 단계마다의 목표치. 클수록 어려운 단계 | 숫자. 단위는 조건에 따름(회, km, %, 일). %는 0~100. 비면 그 단계 없음 | 3, 2, 1, 0 | 앱에 들어감 |

## 조건 번호표

미션(조합) 탭의 조건ID에 쓰는 번호다. 조건은 앱에 들어 있는 것만 쓸 수 있다.

- 번호는 다시 쓰지 않는다. 조건을 없애도 그 번호는 비워 두고, 새 조건은 다음 번호를 받는다.
- 이미 있는 조건의 뜻(세는 방식, 비교)은 바꾸지 않는다. 바꿀 일이 생기면 새 번호로 추가한다.

| 조건ID | 조건 | 비교 | 목표치 단위 |
|---|---|---|---|
| 1 | 급제동 이하 | 이하 | 회 |
| 2 | 급가속 이하 | 이하 | 회 |
| 3 | 깜빡이 없는 차선변경 이하 | 이하 | 회 |
| 4 | 깜빡이 비율 이상 | 이상 | % |
| 5 | 감점 없는 거리 | 이상 | km |
| 6 | 출발 전 안전벨트 | 한 번이라도 | 없음 |
| 7 | 충전 멈춤 | 이하 | % |
| 8 | 배터리 지키기 | 이상 | % |
| 9 | 연속 일수 | 연속 | 일 |

- 목표치 단위가 %인 조건은 0~100으로 적는다.
- 출발 전 안전벨트는 목표치가 없다. 1단계 하나만 쓰고 목표치_1단계에 0을 적는다(2~4단계는 비움).

## 미션 단계 보상

한 줄 = 단계 하나. 키 = 단계. 모든 미션이 같이 쓴다.

| 컬럼 | 뜻 | 형식 | 예 | 구분 |
|---|---|---|---|---|
| 단계 | 1부터 | 숫자 | 3 | 앱에 들어감 |
| 보상_경험치 | 이 단계 미션의 경험치 | 숫자 | 15 | 앱에 들어감 |
| 보상_포인트 | 이 단계 미션의 포인트 | 숫자 | 60 | 앱에 들어감 |

## 아이템

한 줄 = 아이템 하나. 키 = 아이템ID.

| 컬럼 | 뜻 | 형식 | 예 | 구분 |
|---|---|---|---|---|
| 아이템ID | 아이템 번호 | 숫자 | 3 | 앱에 들어감 |
| 종류 | 펫, 소품, 배경 | 셋 중 하나 | 펫 | 앱에 들어감 |
| 이름 | 카드 이름 | 콘텐츠 텍스트 키 | `item_3_name` | 앱에 들어감 |
| 이미지 | 그림 경로 | `기획/디자인/Image/Item/` 아래 PNG의 상대 경로, 확장자 없음. `/`로 나뉜 조각마다 영문·숫자·밑줄. 대소문자까지 파일과 같게 (06 "폴더 구조") | `Pet/Turtle/Turtle_Lv1` | 앱에 들어감 |
| 구매_포인트 | 가격 | 숫자 | 300 | 앱에 들어감 |
